# Analysis notebook

[`Condition_Aware_Peptide_Self_Assembly_ML.ipynb`](Condition_Aware_Peptide_Self_Assembly_ML.ipynb) contains the complete computational analysis for this repository.

The analysis covers:

- source-data audit and cross-database linkage;
- condition, temperature and solvent reconstruction;
- bulk-state and morphology curation;
- molecular-identity definition and 58-feature construction;
- random-split leakage quantification;
- molecule-grouped and publication-aware validation;
- binary hydrogel prediction;
- three-class bulk-state prediction;
- broad morphology prediction;
- fine-morphology independent-support assessment;
- bootstrap uncertainty, sensitivity analyses and error interpretation;
- export of generated figures, tables, datasets and model artifacts.

Data placement and environment setup are described in the repository-level [`README.md`](../README.md) and [`data/README.md`](../data/README.md).
