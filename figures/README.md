# Figures

The SVG files in this directory are concise visual summaries of the principal reported results and are displayed in the repository README.

- `readme_figure_1_leakage.svg` — molecular leakage under conventional random row splitting.
- `readme_figure_2_binary_holdout.svg` — binary hydrogel/non-gel performance on unseen molecules.
- `readme_figure_3_feature_blocks.svg` — feature-block permutation importance.
- `readme_figure_4_morphology_support.svg` — condition-row counts versus independent molecular support for broad morphology classes.

The analysis notebook generates the publication figures directly from the computed results and saves both 300-dpi PNG and vector PDF versions under `paper_outputs/figures/`.
